# TimeCapsule — Digital History Museum

**History, preserved in moments.**

TimeCapsule is an interactive digital history museum that takes visitors on a journey through ancient civilizations, historical discoveries, cultural achievements, and events that shaped humanity.

## Overview

TimeCapsule transforms historical learning into a visual and interactive experience. Explore different eras, discover fascinating stories, learn about significant events, and build your own collection of favorite historical moments.

The website combines an elegant museum-inspired design with simple navigation and interactive features to make exploring history enjoyable.

## Features

- **Interactive Timeline:** Explore five historical eras, from the ancient world to the modern age.
- **Historical Collections:** Discover curated stories about civilizations, inventions, art, science, and exploration.
- **Search Functionality:** Find historical stories using keywords.
- **Era Filters:** Browse events by their historical period.
- **Story Details:** Open individual stories to learn more about their historical significance.
- **Favorites Collection:** Save and remove interesting stories using browser LocalStorage.
- **On This Day:** Discover selected historical events associated with the current date.
- **Responsive Design:** Enjoy a consistent experience across desktop, tablet, and mobile screens.
- **Museum-Inspired Interface:** Explore a warm color palette, elegant typography, and editorial-style layouts.

## Technologies Used

- HTML5 — Website structure and content
- Tailwind CSS — Styling and responsive layouts
- JavaScript — Interactive features and dynamic content
- LocalStorage — Saving favorite stories in the browser
- Google Fonts — Custom typography
- Unsplash — Historical and architectural imagery

## Historical Eras

1. **Ancient World** — Early writing, pyramids, and ancient societies.
2. **Classical Age** — Roman civilization, Greek theatre, and classical ideas.
3. **Medieval World** — Trade networks, scholarship, and cultural exchange.
4. **Renaissance** — Art, scientific discoveries, and new perspectives.
5. **Modern Age** — Industrial innovation and space exploration.

## Getting Started

### Prerequisites

- A modern web browser
- A code editor such as Visual Studio Code
- An internet connection for externally hosted styles, fonts, and images

### Installation

1. Clone this repository:

   ```bash
   git clone https://github.com/YOUR-USERNAME/timecapsule-digital-history-museum.git
   ```

2. Open the project folder:

   ```bash
   cd timecapsule-digital-history-museum
   ```

3. Open `index.html` in your browser.

4. Alternatively, use the Live Server extension in Visual Studio Code.

No additional package installation is required.

## Important Note

The current version uses a sample collection of historical events. The “On This Day” feature is not a complete historical calendar, and its fallback selection does not guarantee that an event occurred on the displayed date. Historical details should be checked against reliable sources before being used for academic research.
